


# Truyền tham số trong C

Ngôn ngữ C truyền tham số theo cơ chế **tham trị (pass-by-value)**. Hàm nhận một bản sao, không sửa được biến gốc.

| 1. Truyền theo giá trị (Pass-by-value)                      | 2. Truyền theo địa chỉ (Simulate Pass-by-reference)         |
| :---------------------------------------------------------- | :---------------------------------------------------------- |
| Hàm chỉ làm việc với bản sao, biến gốc bên ngoài không đổi. | Hàm làm việc trực tiếp trên vùng nhớ, biến gốc bị thay đổi. |
| ```c void change(int x) { x = 10; } ```                     | ```c void change(int *x) { *x = 10; } ```                   |
| *Sửa biến bên ngoài không thành công*                       | *Sửa biến bên ngoài thành công*                             |
