Con Trỏ trong C
Pass by Value vs Pointer

Hiểu rõ tại sao hàm không thể thay đổi biến ngoài — và cách dùng con trỏ để giải quyết điều đó.

1. Vấn đề 2. Pass by Value 3. Con trỏ (Pointer) 4. Không dùng pointer 5. C++ Reference 6. So sánh 7. Tóm tắt
1

Vấn đề: Tại sao hàm không sửa được biến ngoài?

Bạn có một biến a = 5. Bạn muốn viết một hàm change() để đổi giá trị của a thành 10. Điều tưởng chừng đơn giản này lại không hoạt động như bạn nghĩ trong C.

⚠️

Nguyên tắc cốt lõi: C luôn truyền tham số theo tham trị (pass by value) — hàm chỉ nhận một bản sao, không nhận biến gốc.

2

Pass by Value — Truyền theo giá trị

Hãy xem điều gì xảy ra khi bạn truyền a thẳng vào hàm:

C — Truyền tham trị (KHÔNG hoạt động như mong muốn) 
#include <stdio.h>

void change(int x)
{
    x = 10;   // chỉ sửa bản sao, không sửa a
}

int main()
{
    int a = 5;

    change(a);         // truyền GIÁ TRỊ của a

    printf("%d\n", a); // vẫn in ra 5
}
Kết quả
5

📌 Tại sao lại ra 5? Hãy xem sơ đồ bộ nhớ:

Sơ đồ bộ nhớ — Trước khi gọi hàm
a ───▶
5
← biến gốc
Sơ đồ bộ nhớ — Bên trong hàm change()
a ───▶
5
← không đổi
x ───▶
10
← bản sao, bị sửa nhưng biến mất sau khi hàm kết thúc
💡

x là một ô nhớ riêng biệt. Sửa x không ảnh hưởng gì đến a vì chúng nằm ở hai địa chỉ bộ nhớ khác nhau.

3

Giải pháp: Dùng Con Trỏ (Pointer)

Thay vì truyền giá trị, hãy truyền địa chỉ của biến. Hàm sẽ nhận địa chỉ và truy cập trực tiếp vào ô nhớ đó để sửa.

Khai báo hàm nhận con trỏ: void change(int *x) — x giờ lưu một địa chỉ, không phải giá trị.

Gọi hàm với toán tử &: change(&a) — &a lấy địa chỉ bộ nhớ của biến a.

Dereference để sửa: *x = 10 — đi đến địa chỉ mà x đang trỏ tới, rồi ghi giá trị 10 vào đó.

C — Dùng Pointer (HOẠT ĐỘNG đúng) 
#include <stdio.h>

void change(int *x)   // x nhận ĐỊA CHỈ của biến
{
    *x = 10;          // dereference: đến địa chỉ đó và ghi 10
}

int main()
{
    int a = 5;

    change(&a);        // &a = lấy địa chỉ của a

    printf("%d\n", a); // in ra 10
}
Kết quả
10
Sơ đồ bộ nhớ — Con trỏ x trỏ đến a
x ───▶
địa chỉ của a
──▶
a = 5
Khi *x = 10 được thực thi:
x ───▶
địa chỉ của a
──▶
a = 10
✅

x và a cùng trỏ đến một ô nhớ. Khi *x = 10, chính ô nhớ của a bị thay đổi — đó là lý do printf("%d\n", a) in ra 10.

4

Nếu không muốn dùng pointer?

Trong C, nếu không dùng pointer, cách duy nhất còn lại là trả về giá trị mới và tự gán lại:

C — Trả về giá trị (không dùng pointer) 
#include <stdio.h>

int change(int x)
{
    return 10;    // trả về giá trị mới
}

int main()
{
    int a = 5;

    a = change(a); // bắt buộc gán lại: a = giá trị trả về

    printf("%d\n", a); // in ra 10
}
Kết quả
10
⚠️

Lưu ý: bạn phải viết a = change(a), không phải chỉ change(a). Nếu quên gán lại, giá trị trả về bị bỏ qua và a vẫn là 5.

📋 Hai cách hợp lệ trong C
Cách 1 — Pointer change(&a); — hàm nhận int *x
Cách 2 — Return a = change(a); — hàm nhận int x, trả về int

Trong C chuẩn, không có cách thứ ba.

5

C++ Reference — Tham chiếu (Bonus)

Trong C++ (không phải C), có thêm một cú pháp gọn hơn gọi là reference:

C++ — Reference (chỉ dùng được trong C++) 
void change(int &x)   // x là tham chiếu đến biến được truyền vào
{
    x = 10;           // sửa x = sửa trực tiếp biến gốc
}

int main()
{
    int a = 5;

    change(a);         // KHÔNG cần &a — gọi như bình thường
    // a == 10 ngay sau lệnh này
}
Kết quả
10
Reference: x là bí danh (alias) của a — cùng 1 ô nhớ
x ─┐
. ─┤
Ô nhớ = 10
a ─┘

x và a là hai tên khác nhau của cùng một địa chỉ bộ nhớ.

🚫

Lưu ý: int &x là cú pháp của C++. Nếu bạn đang lập trình C thuần (.c), cú pháp này sẽ báo lỗi compile. Chỉ dùng được khi compile bằng g++ hoặc file .cpp.

6

So sánh ba cách

Cách Ngôn ngữ Khai báo hàm Cách gọi Bên trong hàm Kết quả
Pass by value C void change(int x) change(a) x = 10 ❌ a vẫn = 5
Pointer C void change(int *x) change(&a) *x = 10 ✅ a = 10
Return value C int change(int x) a = change(a) return 10 ✅ a = 10
Reference C++ void change(int &x) change(a) x = 10 ✅ a = 10
🔍

C++ Reference và C Pointer cho kết quả giống nhau, nhưng cú pháp của Reference gọn hơn: không cần &a khi gọi, không cần *x bên trong hàm.

7

Tóm tắt nhanh

🎯 Những điều cần nhớ

▸

C luôn truyền tham trị. Khi bạn viết change(a), hàm nhận một bản sao của a — biến gốc không thay đổi.

▸

Dùng pointer để sửa biến ngoài. Truyền &a, nhận int *x, sửa bằng *x = giá_trị.

▸

Hoặc return giá trị mới. Hàm trả về int, bạn tự gán: a = change(a).

▸

C++ có Reference (int &x) — cú pháp gọn hơn pointer, hoạt động tương đương, nhưng không có trong C thuần.

▸

Không có cách thứ ba trong C chuẩn. Chỉ có pointer hoặc return value.
