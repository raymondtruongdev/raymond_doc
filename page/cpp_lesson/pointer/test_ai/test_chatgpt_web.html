Chuyên đề: Con trỏ trong C/C++

Hiểu con trỏ chính là hiểu cách chương trình quản lý bộ nhớ. Pointer là nền tảng của cấu trúc dữ liệu, cấp phát động, hệ điều hành, embedded, driver và nhiều lĩnh vực lập trình hiệu năng cao.

1. Giới thiệu về Con trỏ (Pointer)

Trong lập trình C/C++, Con trỏ (Pointer) là một trong những khái niệm mạnh mẽ nhất nhưng cũng dễ gây nhầm lẫn nhất. Hiểu về con trỏ chính là hiểu cách máy tính quản lý bộ nhớ.

"Con trỏ không phải là một giá trị thông thường, nó là một biến lưu trữ địa chỉ của một ô nhớ khác."

Hình dung đơn giản

Hãy tưởng tượng bộ nhớ là một dãy tủ có khóa. Biến a là một ngăn tủ chứa giá trị. Con trỏ p chỉ ghi lại số tủ nơi giá trị đang nằm.

2. Biến và Bộ nhớ (Variable & Memory)

Mỗi khi khai báo biến, hệ điều hành cấp phát một vùng RAM để lưu dữ liệu. Mỗi vùng RAM đều có một địa chỉ duy nhất.

Các vùng nhớ chính

  • Stack Memory — Biến cục bộ, tham số hàm.
  • Heap Memory — Cấp phát động bằng malloc/new.
  • Data Segment — Biến global, static.
  • Code Segment — Mã máy của chương trình.

3. Khái niệm cơ bản về Pointer

Toán tử Tên gọi Ý nghĩa
& Address Of Lấy địa chỉ biến
* Dereference Truy cập giá trị tại địa chỉ

Ví dụ minh họa 


#include <stdio.h>

int main() {
    int a = 5;
    int *p = &a;

    printf("Gia tri cua a: %d\n", a);
    printf("Dia chi cua a: %p\n", &a);
    printf("Gia tri cua p: %p\n", p);
    printf("Gia tri p tro toi: %d\n", *p);

    *p = 10;

    printf("Gia tri moi cua a: %d\n", a);

    return 0;
}

Bảng quy đổi p + 1

Kiểu dữ liệu sizeof Tăng thêm
char* 1 +1 byte
short* 2 +2 bytes
int* 4 +4 bytes
double* 8 +8 bytes

4. Cách khai báo Pointer

  • int* p;
  • int *p;
  • int * p;

Sai lầm phổ biến 


int* p1, p2;

// p1 là pointer
// p2 chỉ là int bình thường


int *p1, *p2;

// cả p1 và p2 đều là pointer

5. Pass By Value vs Pass By Address

Pass By Value

Trong C, mặc định mọi tham số được truyền theo giá trị. Hàm nhận được một bản sao của biến gốc. Mọi thay đổi bên trong hàm sẽ không ảnh hưởng tới biến bên ngoài.

⚠️ Phần tài liệu gốc kết thúc tại đây. Nội dung Pass By Address chưa xuất hiện trong đoạn nguồn được cung cấp.
