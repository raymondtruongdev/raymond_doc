Hướng dẫn toàn diện về Con trỏ (Pointer) trong C

1. Khai báo con trỏ: Những lưu ý quan trọng

Trong C, việc đặt dấu sao (*) rất quan trọng. Dấu sao gắn liền với tên biến chứ không phải kiểu dữ liệu.

Cách khai báo đúng

int *p;  // p là một con trỏ kiểu int (đúng)
int* p;  // cũng là con trỏ (đúng, nhưng dễ gây nhầm lẫn)

Sai lầm thường gặp

int* p1, p2; 
// p1 là con trỏ int, nhưng p2 CHỈ LÀ biến int bình thường!

Mẹo: Luôn khai báo int *p1, *p2; để đảm bảo tất cả đều là con trỏ.

2. Tại sao cần con trỏ để thay đổi biến?

C truyền tham số theo giá trị (pass by value). Hàm chỉ nhận bản sao, nên muốn sửa biến gốc, ta phải truyền địa chỉ của nó.

void change(int *x) {
    *x = 10; // "Đi tới địa chỉ x, ghi giá trị 10 vào đó"
}
// Gọi: change(&a);

3. So sánh C Pointer vs C++ Reference

Đặc điểmC (Pointer)C++ (Reference)
Cú phápint *xint &x
Cách gọichange(&a)change(a)
Bản chấtChứa địa chỉBí danh (alias) của biến

Tóm tắt kỹ thuật

  • Khai báo nhiều con trỏ: Sử dụng int *p1, *p2, *p3;.
  • Truyền tham số: C bắt buộc dùng pointer &a hoặc trả về giá trị mới (return).
  • Toán tử *: Khi khai báo, nó dùng để tạo pointer. Khi sử dụng trong hàm, nó dùng để truy cập/thay đổi giá trị tại địa chỉ đó.
