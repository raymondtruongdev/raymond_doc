1. Variable (Biến) là gì?

Một biến là một vùng nhớ dùng để lưu dữ liệu. 

int a = 5;

Có thể hình dung:

a → 5

2. Pass By Value trong C

C luôn truyền tham số theo giá trị (Pass By Value). Nghĩa là hàm sẽ nhận một bản sao của dữ liệu. 

#include <stdio.h>

void change(int x)
{
    x = 10;
}

int main()
{
    int a = 5;

    change(a);

    printf("%d\n", a);
}
Kết quả: 5

3. Vì sao a không thay đổi?

Khi gọi: 

change(a);

Hệ thống tạo ra một bản sao:

a = 5
x = 5 (bản sao của a)

Sau đó: 

x = 10;
a = 5
x = 10

Chỉ x thay đổi, a hoàn toàn không bị ảnh hưởng.

4. Pointer là gì?

Pointer là biến dùng để lưu địa chỉ bộ nhớ. 

int a = 5;

int *p = &a;
p
↓
a = 5

Ý nghĩa ký hiệu 

a      // giá trị
&a     // địa chỉ của a

p      // địa chỉ đang lưu trong pointer
*p     // giá trị tại địa chỉ p trỏ tới

5. Thay đổi biến bằng Pointer 

#include <stdio.h>

void change(int *x)
{
    *x = 10;
}

int main()
{
    int a = 5;

    change(&a);

    printf("%d\n", a);
}
Kết quả: 10

Điều gì xảy ra?

Khi gọi: 

change(&a);

Hàm nhận địa chỉ của a.

x
↓
a = 5

Khi thực hiện: 

*x = 10;

Nghĩa là: 

a = 10;

Vì x đang trỏ trực tiếp tới a.

6. Không dùng Pointer thì làm sao?

Trong C chuẩn, nếu không dùng pointer thì không thể thay đổi trực tiếp biến của caller.

Cách làm là trả về giá trị mới: 

int change(int x)
{
    x = 10;
    return x;
}

int main()
{
    int a = 5;

    a = change(a);
}

Hoặc: 

int change(int x)
{
    return 10;
}
Trong C chuẩn chỉ có hai cách:
  • Dùng Pointer
  • Trả về giá trị mới rồi gán lại

7. C++ Reference (&)

Đoạn code sau là C++, không phải C: 

void change(int &x)
{
    x = 10;
}

int main()
{
    int a = 5;

    change(a);
}

int &x là reference (tham chiếu).

x ----+
        |
a ----+

x trở thành một bí danh (alias) của a. 

x = 10;

Thực chất tương đương: 

a = 10;

So sánh với Pointer trong C

C++

void change(int &x)
{
    x = 10;
}

change(a);

C

void change(int *x)
{
    *x = 10;
}

change(&a);
Reference và Pointer cho kết quả gần như tương đương, nhưng Reference có cú pháp ngắn gọn hơn.

8. Tổng kết cần nhớ

  • C luôn truyền tham số theo giá trị (Pass By Value).
  • int x nhận bản sao dữ liệu.
  • int *x nhận địa chỉ.
  • *x truy cập dữ liệu tại địa chỉ đó.
  • Muốn sửa biến bên ngoài hàm trong C → dùng Pointer.
  • Hoặc trả về giá trị mới rồi gán lại.
  • int &x là Reference của C++, không tồn tại trong C.
  • Reference là bí danh của biến gốc.
