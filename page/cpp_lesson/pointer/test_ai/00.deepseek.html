📌 Con trỏ, tham số & bộ nhớ trong C

✍️ Giải thích chi tiết từ tham trị, tham chiếu, con trỏ đến malloc – dành cho người mới học

1️⃣ Truyền tham số trong C – Pass by Value

Trong C, mọi thứ đều được truyền theo giá trị (pass by value). Nghĩa là khi gọi hàm, một bản sao của đối số được tạo ra cho tham số. Thay đổi bên trong hàm không ảnh hưởng đến biến gốc bên ngoài. 

#include <stdio.h>

void change(int x) {
    x = 10;           // chỉ sửa trên bản sao
}

int main() {
    int a = 5;
    change(a);
    printf("%d\n", a);   // Kết quả: 5
    return 0;
}
📍 Sơ đồ hoạt động: a ---> 5 (biến gốc) x ---> 5 (bản sao của a) Sau khi x = 10: a ---> 5 x ---> 10 (a không thay đổi)
⚡ Kết luận: Nếu hàm nhận int x thì chỉ sửa được bản sao. Muốn thay đổi giá trị biến gốc bên ngoài → phải dùng con trỏ (pointer) hoặc trả về giá trị mới.

2️⃣ Dùng con trỏ – Giải pháp trong C chuẩn

Để thay đổi trực tiếp biến a từ bên trong hàm, ta truyền địa chỉ (&a) và dùng con trỏ để thao tác gián tiếp. 

#include <stdio.h>

void change(int *x) {    // nhận địa chỉ của biến
    *x = 10;             // *x = truy cập vào vùng nhớ mà x trỏ tới
}

int main() {
    int a = 5;
    change(&a);          // truyền địa chỉ của a
    printf("%d\n", a);   // Kết quả: 10
    return 0;
}
🔍 Điều gì xảy ra? Ban đầu: a = 5 change(&a) → x trỏ đến địa chỉ của a x (địa chỉ của a) ---> a = 5 Khi *x = 10: "*x" nghĩa là "đi đến ô nhớ mà x đang trỏ tới và gán giá trị 10" ⇒ a = 10
✅ Cách nhớ đơn giản:
▪️ void change(int x) → x là bản sao → không sửa được biến gốc.
▪️ void change(int *x) → x là địa chỉ của biến gốc → dùng *x = ... để sửa gốc.

3️⃣ Không dùng con trỏ – Trả về giá trị mới

Nếu bạn không muốn dùng pointer, hãy để hàm trả về giá trị đã thay đổi và gán lại cho biến ban đầu.

#include <stdio.h>

int change(int x) {
    x = 10;
    return x;          // trả về giá trị mới
}

int main() {
    int a = 5;
    a = change(a);      // gán kết quả trả về cho a
    printf("%d\n", a);  // 10
    return 0;
}

Hoặc đơn giản hơn:

int change(int x) { return 10; }   // luôn trả về 10
⚠️ Lưu ý: Trong C chuẩn, không có cách thứ ba ngoài con trỏ hoặc return & gán lại để thay đổi giá trị biến cục bộ của caller.

4️⃣ C++ reference – Tham chiếu (không có trong C)

Trong C++, cú pháp int &x tạo một tham chiếu – một bí danh (alias) của biến gốc. Code C++ sau đây sẽ sửa được a mà không cần con trỏ, nhưng C KHÔNG hỗ trợ. 

// C++ code (not C)
#include <iostream>
void change(int &x) {
    x = 10;
}
int main() {
    int a = 5;
    change(a);
    std::cout << a;   // 10
    return 0;
}
📌 C++ reference: x trở thành tên khác của a, cùng ô nhớ → thay x là thay a. Trong C, để đạt được hiệu quả tương tự, bắt buộc dùng con trỏ: change(&a) và *x = 10;.

📘 C (pointer)

void change(int *x) {
    *x = 10;
}
int main() {
    int a = 5;
    change(&a);
}

Gọi: change(&a); , bên trong dùng *x

📙 C++ (reference)

void change(int &x) {
    x = 10;
}
int main() {
    int a = 5;
    change(a);
}

Cú pháp gọn hơn, nhưng C không có

💡 Tại sao reference được ưa chuộng trong C++? Vì cú pháp trong sáng: change(a); và bên trong x = 10; thay vì *x = 10;.
🔸 Nhưng trong C, con trỏ là cách duy nhất để mô phỏng tham chiếu.

5️⃣ Con trỏ & bộ nhớ động – malloc

Khi bạn cần cấp phát bộ nhớ khi chạy (mảng kích thước thay đổi, cấu trúc dữ liệu động), C sử dụng malloc() từ thư viện <stdlib.h>. Con trỏ giữ địa chỉ vùng nhớ vừa cấp. 


#include <stdio.h>
#include <stdlib.h>

int main() {
    // Cấp phát bộ nhớ cho 1 số nguyên
    int *ptr = (int*) malloc(sizeof(int));
    if (ptr == NULL) {
        printf("Cấp phát thất bại\n");
        return 1;
    }
    *ptr = 42;             // gán giá trị qua con trỏ
    printf("Giá trị: %d\n", *ptr);
    free(ptr);             // giải phóng bộ nhớ
    return 0;
}
🧠 Hình dung:
ptr (biến con trỏ, nằm trên stack) ----> [vùng nhớ heap chứa số 42]

malloc trả về địa chỉ, ptr lưu địa chỉ đó. Dùng *ptr để truy cập giá trị.
⚠️ Nhớ luôn kiểm tra malloc thành công và free để tránh rò rỉ bộ nhớ.

📌 Mảng động với malloc

int n = 5;
int *arr = (int*) malloc(n * sizeof(int));
for (int i = 0; i < n; i++) {
    arr[i] = i * 10;   // arr[i] tương đương *(arr + i)
}
free(arr);

Con trỏ cho phép thao tác linh hoạt với bộ nhớ heap, tạo nên sức mạnh của C trong hệ thống nhúng và lập trình hệ thống.

6️⃣ Tổng kết logic – Tóm gọn dễ nhớ

  • Pass by value: C luôn sao chép giá trị đối số. Hàm không thể thay đổi biến gốc.
  • Muốn thay đổi biến gốc:
    • Cách 1: Truyền địa chỉ (con trỏ) → change(&a); và hàm nhận int *x → gán *x = newValue;
    • Cách 2: Trả về giá trị mới và gán: a = change(a);
  • Con trỏ (Pointer): Là biến lưu địa chỉ bộ nhớ. Khai báo int *p;, lấy địa chỉ &a, truy cập giá trị *p.
  • malloc: Cấp phát bộ nhớ vùng heap, trả về con trỏ void*, cần ép kiểu và giải phóng bằng free().
  • So sánh C vs C++: C++ có tham chiếu (reference) giúp cú pháp gọn nhưng C không có, thay vào đó dùng pointer.
🧪 Mẹo ghi nhớ siêu tốc:
▪️ change(a) → bản sao, không đổi a gốc.
▪️ change(&a) cùng với int *x → *x = 10 làm thay đổi a.
▪️ Nếu không dùng con trỏ → trả về kết quả rồi gán lại.
▪️ Malloc tạo vùng nhớ mới trên heap, chỉ con trỏ mới “chạm” tới được.

7️⃣ Đoạn mã giả C++ thường gây nhầm lẫn

void change(int &x) {
    x = 10;
}
int main() {
    int a = 5;
    change(a);
}

Đoạn này KHÔNG phải C chuẩn. Đây là C++ dùng tham chiếu. Nếu biên dịch với trình biên dịch C sẽ báo lỗi. Trong C bạn phải viết: 

void change(int *x) { *x = 10; }
int main() { int a = 5; change(&a); }

📎 Hình dung “bản sao” và “địa chỉ”

📍 Kịch bản 1: change(int x) a (5) → bản sao x = 5 x = 10 → a vẫn là 5 📍 Kịch bản 2: change(int *x) và gọi change(&a) a = 5 x = địa chỉ của a (x trỏ tới a) *x = 10 👉 ghi 10 vào ô nhớ của a ⇒ a = 10

Nguyên lý cốt lõi: con trỏ cho phép hàm “nhìn thấy” và chỉnh sửa vùng nhớ của biến bên ngoài. Nếu không có con trỏ, mọi thứ chỉ là bản sao.

📝 Bài học mở rộng về malloc – cấp phát mảng và cấu trúc

#include <stdio.h>
#include <stdlib.h>

typedef struct {
    char name[20];
    int age;
} Student;

int main() {
    Student *sv = (Student*) malloc(sizeof(Student));
    if (sv) {
        sv->age = 22;   // tương đương (*sv).age = 22;
        printf("Tuổi: %d\n", sv->age);
        free(sv);
    }
    return 0;
}

Con trỏ cho phép truy cập vùng nhớ heap một cách linh hoạt, tạo nên các cấu trúc dữ liệu động như linked list, tree, ...

✅ Tổng kết cuối cùng (dành cho newbie)

🔹 Tham trị (value)

Hàm nhận bản sao, không ảnh hưởng bên ngoài. An toàn nhưng không sửa được biến gốc.

🔸 Tham chiếu gián tiếp (pointer)

Truyền địa chỉ, dùng * để thay đổi giá trị gốc. Là phương pháp chính trong C.

🔹 Return & assign

Thay đổi bằng giá trị trả về, không cần pointer nhưng chỉ hiệu quả với một giá trị.

🚀 Lời khuyên: Khi bắt đầu học C, hãy luyện tập viết các hàm swap, thay đổi giá trị bằng con trỏ. Hiểu rõ ký hiệu & (lấy địa chỉ) và * (giá trị tại địa chỉ). Sau đó nắm malloc/free để làm chủ bộ nhớ động. Đây là nền tảng vững chắc cho lập trình hệ thống.
