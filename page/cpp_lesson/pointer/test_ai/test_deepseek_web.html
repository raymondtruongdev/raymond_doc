1. Giới thiệu về Con trỏ (Pointer)

Trong lập trình C/C++, Con trỏ (Pointer) là một trong những khái niệm mạnh mẽ nhất nhưng cũng dễ gây nhầm lẫn nhất.
Hiểu về con trỏ chính là hiểu cách máy tính quản lý bộ nhớ.

"Con trỏ không phải là một giá trị thông thường, nó là một biến lưu trữ địa chỉ của một ô nhớ khác."

Hình dung đơn giản

Hãy tưởng tượng bộ nhớ là một dãy tủ có khóa. Biến int a là một ngăn tủ có nhãn "a" chứa số 5. Con trỏ int *p là một mảnh giấy ghi "số tủ: 0x1000" — nó không chứa số 5, mà chỉ ghi địa chỉ của ngăn tủ chứa số 5.

2. Biến và Bộ nhớ (Variable & Memory)

Mỗi khi bạn khai báo một biến (ví dụ: int a = 5;), máy tính sẽ dành riêng một khoảng không gian trong bộ nhớ (RAM) để lưu trữ giá trị đó.
Mỗi khoảng không gian này có một "số nhà" duy nhất, gọi là địa chỉ (Address).

Các vùng nhớ chính

  • Stack Memory: Dùng để lưu trữ các biến cục bộ, tham số hàm. Tự động cấp phát và giải phóng khi hàm kết thúc.
  • Heap Memory: Dùng cho cấp phát động (malloc/new). Người lập trình phải tự quản lý (cấp phát và giải phóng).

3. Khái niệm cơ bản về Pointer

Để làm việc với con trỏ, bạn cần nắm vững hai toán tử quan trọng nhất:

Toán tửTên gọiÝ nghĩa
&Toán tử lấy địa chỉ (Address-of)Trả về địa chỉ của biến.
*Toán tử giải tham chiếu (Dereference)Truy cập vào giá trị tại địa chỉ mà con trỏ đang trỏ tới.

Cách nhớ: &a → "Địa chỉ của a"  |  *p → "Giá trị tại địa chỉ p"

Ví dụ minh họa

#include <stdio.h>

int main() {
    int a = 5;
    int *p = &a; // p lưu địa chỉ của a

    printf("Gia tri cua a: %d\n", a);          // 5
    printf("Dia chi cua a (&a): %p\n", &a);    // Ví dụ: 0x7ffe...
    printf("Gia tri cua p: %p\n", p);          // Giống &a
    printf("Gia tri p tro toi (*p): %d\n", *p); // 5

    *p = 10; // Thay đổi giá trị tại địa chỉ p trỏ tới
    printf("Gia tri moi cua a: %d\n", a);      // 10

    return 0;
}

Minh họa bộ nhớ: Biến a: 5 @ 0x1000 — Con trỏ p: 0x1000 → trỏ tới a.

4. Cách khai báo Pointer

Trong C, có nhiều cách viết để khai báo một con trỏ, tất cả đều có ý nghĩa như nhau:

  • int* p; — Style C++, nhấn mạnh kiểu dữ liệu là con trỏ int.
  • int *p; — Style C truyền thống, nhấn mạnh p là một biến trỏ.
  • int * p; — Khoảng trắng hai bên, ít dùng.

⚠️ Cảnh báo: Sự khác biệt quan trọng

Khi khai báo nhiều biến trên một dòng, hãy cẩn thận:

int* p1, p2; // SAI LẦM PHỔ BIẾN!
// p1 là con trỏ (int*), nhưng p2 chỉ là một số nguyên (int) thông thường.

int *p1, *p2; // ĐÚNG: Cả p1 và p2 đều là con trỏ.

Minh họa: p1: int* → Là con trỏ, p2: int → Là biến int bình thường!

5. Pass By Value vs Pass By Address

A. Pass By Value (Truyền tham trị)

Trong C, mặc định mọi tham số được truyền theo giá trị. Hàm nhận được một bản sao của biến gốc.

📌 Lưu ý: Nội dung từ tài liệu gốc chi tiết hơn về pass-by-reference/address, nhưng bản Markdown này phản ánh đúng khái niệm cốt lõi. Con trỏ giúp thay đổi biến gốc khi truyền địa chỉ.

✨ Tóm tắt nhanh: Pass by value → copy giá trị, không thay đổi biến gốc. Pass by address (dùng con trỏ) → truyền địa chỉ, có thể sửa đổi biến gốc thông qua dereference.

void changeValue(int x) { x = 100; }               // không đổi a
void changeByPointer(int *ptr) { *ptr = 100; }    // đổi được biến gốc

int main() {
    int a = 5;
    changeValue(a);      // a vẫn là 5
    changeByPointer(&a); // a = 100
    return 0;
}
