Biến và Bộ nhớ

Trước khi học về con trỏ, bạn cần hiểu cách máy tính lưu trữ biến trong bộ nhớ.

Mỗi biến bạn khai báo sẽ được cấp phát một vị trí trong bộ nhớ (memory address). Biến int a = 5 không chỉ chứa giá trị 5, mà còn có một địa chỉ cụ thể trong RAM.

Sơ đồ bộ nhớ cho biến int a = 5
Địa chỉ ───▶
0x7ffee4
← Địa chỉ bộ nhớ (memory address)
Giá trị ───▶
5
← Giá trị lưu trong ô nhớ đó

Bộ nhớ máy tính được chia thành các vùng chính:

graph TD A[Memory] --> B[Stack] A --> C[Heap] A --> D[Data Segment] A --> E[Code Segment] B --> B1[Biến cục bộ] B --> B2[Tham số hàm] B --> B3[Địa chỉ trả về] C --> C1[malloc / new] C --> C2[Dynamic memory] D --> D1[Biến global] D --> D2[Biến static] E --> E1[Code chương trình]
💡

Stack: Tự động quản lý, biến cục bộ được cấp phát và giải phóng tự động.
Heap: Bạn phải tự quản lý bằng malloc() và free().

Pointer cơ bản — Con trỏ là gì?

Con trỏ (pointer) là một biến lưu địa chỉ bộ nhớ của một biến khác, thay vì lưu giá trị trực tiếp.

Nếu int a = 5 lưu giá trị 5, thì int *p = &a lưu địa chỉ của a.

Ví dụ cơ bản về pointer 
#include 

int main() {
    int a = 5;        // Biến a chứa giá trị 5
    int *p = &a;      // p là con trỏ, chứa địa chỉ of a

    printf("Giá trị của a: %d\n", a);           // 5
    printf("Địa chỉ của a: %p\n", &a);          // 0x7ffee4 (ví dụ)
    printf("Giá trị của p: %p\n", p);           // 0x7ffee4 (giống &a)
    printf("Giá trị tại địa chỉ p trỏ tới: %d\n", *p); // 5

    return 0;
}
Kết quả
Giá trị của a: 5
Địa chỉ của a: 0x7ffee4b8a9bc
Giá trị của p: 0x7ffee4b8a9bc
Giá trị tại địa chỉ p trỏ tới: 5
Sơ đồ pointer trỏ đến biến a
a ───▶
5
← Biến a tại địa chỉ 0x1000
p ───▶
0x1000
← p chứa địa chỉ của a
*p dereference ──────────────▶ Đi đến địa chỉ 0x1000, lấy giá trị 5

Ý nghĩa của * và &

📌 Toán tử & — Lấy địa chỉ (Address-of)

Toán tử & trả về địa chỉ bộ nhớ của biến.

Toán tử & — Lấy địa chỉ 
#include 

int main() {
    int a = 10;
    int *p = &a;  // &a = lấy địa chỉ của a

    printf("a = %d\n", a);        // 10
    printf("&a = %p\n", &a);      // 0x7ffee4b8a9bc (địa chỉ của a)
    printf("p = %p\n", p);        // 0x7ffee4b8a9bc (p chứa địa chỉ của a)

    return 0;
}

📌 Toán tử * — Dereference (Giải tham chiếu)

Toán tử * dùng để truy cập giá trị tại địa chỉ mà pointer đang trỏ tới.

Toán tử * — Dereference 
#include 

int main() {
    int a = 10;
    int *p = &a;

    printf("*p = %d\n", *p);  // 10 — lấy giá trị tại địa chỉ p

    *p = 20;  // Sửa giá trị tại địa chỉ p trỏ tới (tức là sửa a)
    printf("a = %d\n", a);    // 20 — a đã thay đổi!

    return 0;
}
💡

Cách nhớ đơn giản:
&a → "Địa chỉ của a"
*p → "Giá trị tại địa chỉ p"

Minh họa * và &
a ───▶
10
← Địa chỉ: 0x1000
&a ───▶
0x1000
← Trả về địa chỉ
*p ───▶
10
← Trả về giá trị tại 0x1000

Pass by Value — Truyền theo giá trị

Bạn có một biến a = 5. Bạn muốn viết một hàm change() để đổi giá trị của a thành 10. Điều tưởng chừng đơn giản này lại không hoạt động như bạn nghĩ trong C.

⚠️

Nguyên tắc cốt lõi: C luôn truyền tham số theo tham trị (pass by value) — hàm chỉ nhận một bản sao, không nhận biến gốc.

Hãy xem điều gì xảy ra khi bạn truyền a thẳng vào hàm:

C — Truyền tham trị (KHÔNG hoạt động như mong muốn) 
#include 

void change(int x)
{
    x = 10;   // chỉ sửa bản sao, không sửa a
}

int main()
{
    int a = 5;

    change(a);         // truyền GIÁ TRỊ của a

    printf("%d\n", a); // vẫn in ra 5
}
Kết quả
5

📌 Tại sao lại ra 5? Hãy xem sơ đồ bộ nhớ:

Sơ đồ bộ nhớ — Trước khi gọi hàm
a ───▶
5
← biến gốc
Sơ đồ bộ nhớ — Bên trong hàm change()
a ───▶
5
← không đổi
x ───▶
10
← bản sao, bị sửa nhưng biến mất sau khi hàm kết thúc
💡

x là một ô nhớ riêng biệt. Sửa x không ảnh hưởng gì đến a vì chúng nằm ở hai địa chỉ bộ nhớ khác nhau.

Pass by Address — Truyền theo địa chỉ

Thay vì truyền giá trị, hãy truyền địa chỉ của biến. Hàm sẽ nhận địa chỉ và truy cập trực tiếp vào ô nhớ đó để sửa.

Khai báo hàm nhận con trỏ: void change(int *x) — x giờ lưu một địa chỉ, không phải giá trị.

Gọi hàm với toán tử &: change(&a) — &a lấy địa chỉ bộ nhớ của biến a.

Dereference để sửa: *x = 10 — đi đến địa chỉ mà x đang trỏ tới, rồi ghi giá trị 10 vào đó.

C — Dùng Pointer (HOẠT ĐỘNG đúng) 
#include 

void change(int *x)   // x nhận ĐỊA CHỈ của biến
{
    *x = 10;          // dereference: đến địa chỉ đó và ghi 10
}

int main()
{
    int a = 5;

    change(&a);        // &a = lấy địa chỉ của a

    printf("%d\n", a); // in ra 10
}
Kết quả
10
Sơ đồ bộ nhớ — Con trỏ x trỏ đến a
x ───▶
địa chỉ của a
──▶
a = 5
Khi *x = 10 được thực thi:
x ───▶
địa chỉ của a
──▶
a = 10
✅

x và a cùng trỏ đến một ô nhớ. Khi *x = 10, chính ô nhớ của a bị thay đổi — đó là lý do printf("%d\n", a) in ra 10.

C++ Reference — Tham chiếu

Trong C++ (không phải C), có thêm một cú pháp gọn hơn gọi là reference:

C++ — Reference (chỉ dùng được trong C++) 
void change(int &x)   // x là tham chiếu đến biến được truyền vào
{
    x = 10;           // sửa x = sửa trực tiếp biến gốc
}

int main()
{
    int a = 5;

    change(a);         // KHÔNG cần &a — gọi như bình thường
    // a == 10 ngay sau lệnh này
}
Kết quả
10
Reference: x là bí danh (alias) của a — cùng 1 ô nhớ
x ─┐
. ─┤
Ô nhớ = 10
a ─┘

x và a là hai tên khác nhau của cùng một địa chỉ bộ nhớ.

🚫

Lưu ý: int &x là cú pháp của C++. Nếu bạn đang lập trình C thuần (.c), cú pháp này sẽ báo lỗi compile. Chỉ dùng được khi compile bằng g++ hoặc file .cpp.

Đặc điểm Pointer (C) Reference (C++)
Khai báo int *p = &a; int &r = a;
Gọi hàm change(&a) change(a)
Trong hàm *p = 10 r = 10
NULL Có thể NULL Không thể NULL

Các loại Pointer đặc biệt

📌 NULL Pointer

Con trỏ NULL là con trỏ không trỏ đến bất kỳ địa chỉ nào. Đây là giá trị an toàn để khởi tạo pointer.

NULL Pointer 
#include 
#include 

int main() {
    int *p = NULL;  // p không trỏ đến đâu cả

    if (p == NULL) {
        printf("p is NULL\n");
    }

    // Luôn kiểm tra NULL trước khi dereference
    if (p != NULL) {
        printf("%d\n", *p);  // Chỉ thực hiện nếu p không NULL
    }

    return 0;
}
⚠️

Dereference NULL pointer sẽ gây crash chương trình (segmentation fault).

📌 Wild Pointer (Con trỏ hoang)

Wild pointer là con trỏ chưa được khởi tạo, chứa một địa chỉ rác ngẫu nhiên.

Wild Pointer — NGUY HIỂM 
#include 

int main() {
    int *p;  // ❌ Wild pointer — chưa khởi tạo, chứa địa chỉ rác

    // printf("%d\n", *p);  // ❌ NGUY HIỂM — có thể crash hoặc đọc rác

    int a = 5;
    p = &a;  // ✅ Bây giờ p đã an toàn

    printf("%d\n", *p);  // ✅ 5

    return 0;
}
✅

Best practice: Luôn khởi tạo pointer khi khai báo: int *p = NULL;

📌 Dangling Pointer (Con trỏ treo)

Dangling pointer là con trỏ trỏ đến bộ nhớ đã được giải phóng hoặc biến đã ra khỏi scope.

Dangling Pointer — NGUY HIỂM 
#include 
#include 

int* createArray() {
    int arr[10];  // Biến cục bộ trên stack
    return arr;   // ❌ TRẢ VỀ ĐỊA CHỈ CỦA BIẾN CỤC BỘ — DANGEROUS!
}

int main() {
    int *p = createArray();  // p là dangling pointer

    // printf("%d\n", p[0]);  // ❌ Undefined behavior — stack memory đã bị giải phóng

    // Ví dụ khác với malloc/free:
    int *q = malloc(sizeof(int) * 10);
    free(q);  // Giải phóng bộ nhớ
    // q bây giờ là dangling pointer

    // printf("%d\n", *q);  // ❌ NGUY HIỂM — use after free

    q = NULL;  // ✅ Sau khi free, gán NULL để tránh dangling

    return 0;
}
Dangling Pointer — Bộ nhớ đã được giải phóng
p ───▶
0x5000
← p vẫn chứa địa chỉ
───▶
0x5000
← Bộ nhớ đã free — KHÔNG còn hợp lệ!

Array & Pointer

Trong C, tên mảng thực chất là một con trỏ hằng trỏ đến phần tử đầu tiên của mảng.

Mảng và Pointer tương đương 
#include 

int main() {
    int arr[] = {10, 20, 30, 40, 50};
    int *p = arr;  // p trỏ đến phần tử đầu tiên của arr

    // Các cách truy cập tương đương:
    printf("%d\n", arr[0]);   // 10
    printf("%d\n", *arr);     // 10
    printf("%d\n", p[0]);     // 10
    printf("%d\n", *p);       // 10

    printf("%d\n", arr[2]);   // 30
    printf("%d\n", *(arr + 2)); // 30
    printf("%d\n", p[2]);     // 30
    printf("%d\n", *(p + 2)); // 30

    return 0;
}
💡

arr[i] thực chất là *(arr + i) — đi đến địa chỉ arr + i rồi lấy giá trị.

Sơ đồ mảng và pointer
arr ───▶
10
20
30
40
50
p ───▶
10
← p trỏ đến arr[0]
p+2 ───▶
30
← p+2 trỏ đến arr[2]
⚠️

Khác biệt quan trọng: arr là con trỏ hằng — bạn không thể gán arr = p hay arr++. Nhưng p là biến pointer bình thường, có thể thay đổi.

Pointer Arithmetic — Số học con trỏ

Bạn có thể thực hiện các phép toán trên pointer. Khi cộng/trừ, pointer sẽ tự động nhân với kích thước kiểu dữ liệu.

Pointer Arithmetic 
#include 

int main() {
    int arr[] = {10, 20, 30, 40, 50};
    int *p = arr;

    printf("p = %p\n", p);        // 0x1000 (giả sử)
    printf("p + 1 = %p\n", p + 1); // 0x1004 (tăng 4 bytes vì sizeof(int) = 4)
    printf("p + 2 = %p\n", p + 2); // 0x1008

    // Truy cập giá trị:
    printf("*p = %d\n", *p);       // 10
    printf("*(p+1) = %d\n", *(p+1)); // 20
    printf("*(p+2) = %d\n", *(p+2)); // 30

    // Pointer subtraction:
    int *q = &arr[4];
    printf("q - p = %ld\n", q - p); // 4 (số phần tử, không phải bytes)

    return 0;
}
Pointer arithmetic với int (sizeof = 4 bytes)
0x1000
10 ← p
0x1004
20 ← p+1
0x1008
30 ← p+2
0x100C
40 ← p+3
0x1010
50 ← p+4

Mỗi lần p + 1, pointer tăng 4 bytes (với int).

Kiểu dữ liệu sizeof p + 1 tăng bao nhiêu?
char * 1 byte +1 byte
short * 2 bytes +2 bytes
int * 4 bytes +4 bytes
long * 8 bytes +8 bytes
double * 8 bytes +8 bytes

malloc và free — Cấp phát bộ nhớ động

Khi bạn cần cấp phát bộ nhớ tại runtime (kích thước không biết trước), dùng malloc() để cấp phát trên heap và free() để giải phóng.

malloc và free 
#include 
#include 

int main() {
    // Cấp phát mảng 5 số nguyên
    int *arr = malloc(5 * sizeof(int));

    if (arr == NULL) {
        printf("Không thể cấp phát bộ nhớ!\n");
        return 1;
    }

    // Sử dụng như mảng bình thường
    for (int i = 0; i < 5; i++) {
        arr[i] = (i + 1) * 10;
    }

    for (int i = 0; i < 5; i++) {
        printf("%d ", arr[i]);  // 10 20 30 40 50
    }
    printf("\n");

    // QUAN TRỌNG: Giải phóng bộ nhớ khi không dùng nữa
    free(arr);
    arr = NULL;  // Tránh dangling pointer

    return 0;
}
✅

Best practices:
1. Luôn kiểm tra malloc() trả về NULL
2. Luôn free() bộ nhớ khi không dùng
3. Sau free(), gán pointer = NULL để tránh dangling

Stack vs Heap

...biến cục bộ
← Tự động quản lý

arr[3]
arr[4]
← Bạn phải tự quản lý (malloc/free)
⚠️

Memory leak: Nếu bạn malloc() mà không free(), bộ nhớ sẽ bị rò rỉ — chương trình sẽ tốn ngày càng nhiều RAM.

Struct Pointer

Khi làm việc với struct, pointer giúp tránh copy toàn bộ struct khi truyền vào hàm — chỉ truyền địa chỉ, tiết kiệm bộ nhớ và thời gian.

Struct Pointer 
#include 
#include 

typedef struct {
    char name[50];
    int age;
    float gpa;
} Student;

// ❌ Cách 1: Truyền cả struct (copy toàn bộ)
void printStudent(Student s) {
    printf("%s - %d tuổi - GPA: %.2f\n", s.name, s.age, s.gpa);
}

// ✅ Cách 2: Truyền pointer (chỉ truyền địa chỉ)
void printStudentPtr(Student *s) {
    // Dùng (*s).name hoặc s->name
    printf("%s - %d tuổi - GPA: %.2f\n", s->name, s->age, s->gpa);
}

// ✅ Cách 3: Dùng -> operator (ngắn gọn hơn)
void updateGPA(Student *s, float newGPA) {
    s->gpa = newGPA;  // Tương đương (*s).gpa = newGPA
}

int main() {
    Student sv1 = {"Nguyen Van A", 20, 3.5};

    printStudent(sv1);       // Copy cả struct
    printStudentPtr(&sv1);   // Chỉ truyền địa chỉ

    updateGPA(&sv1, 3.8);
    printf("GPA mới: %.2f\n", sv1.gpa);  // 3.8

    return 0;
}
💡

Toán tử ->: s->name tương đương (*s).name — dereference rồi truy cập field. Toán tử -> ngắn gọn và dễ đọc hơn.

Struct Pointer — Tránh copy
sv1 ───▶
name: "A"
age: 20
gpa: 3.5
← Toàn bộ struct
ptr ───▶
địa chỉ của sv1
← Chỉ truyền địa chỉ, không copy

Const Pointer

Có 3 kiểu kết hợp const với pointer, mỗi kiểu có ý nghĩa khác nhau:

Kiểu Khai báo Ý nghĩa Có thể...
Pointer to const const int *p
int const *p		 p trỏ đến giá trị không thể sửa qua p ✅ p = &b (đổi pointer)
❌ *p = 10 (không sửa giá trị)
Const pointer int * const p = &a p là pointer hằng, không thể đổi địa chỉ ❌ p = &b (không đổi pointer)
✅ *p = 10 (sửa giá trị)
Const pointer to const const int * const p = &a Vừa không đổi pointer, vừa không sửa giá trị ❌ p = &b (không đổi pointer)
❌ *p = 10 (không sửa giá trị)
Const Pointer examples 
#include 

int main() {
    int a = 5, b = 10;

    // 1. Pointer to const
    const int *p1 = &a;
    // *p1 = 20;  // ❌ Lỗi: không thể sửa giá trị qua p1
    p1 = &b;       // ✅ OK: có thể đổi pointer

    // 2. Const pointer
    int * const p2 = &a;
    *p2 = 20;      // ✅ OK: có thể sửa giá trị
    // p2 = &b;    // ❌ Lỗi: không thể đổi pointer

    // 3. Const pointer to const
    const int * const p3 = &a;
    // *p3 = 20;   // ❌ Lỗi: không thể sửa giá trị
    // p3 = &b;    // ❌ Lỗi: không thể đổi pointer

    return 0;
}
💡

Cách đọc: Đọc từ phải sang trái. int * const p → "p is const pointer to int". const int *p → "p is pointer to const int".

10 Lỗi Pointer thường gặp

Dưới đây là 10 lỗi phổ biến khi làm việc with pointer mà người mới học thường gặp:

  • Dereference NULL pointer

    Truy cập giá trị qua pointer NULL sẽ gây crash.

    int *p = NULL;
    printf("%d\n", *p); // ❌ SEGMENTATION FAULT

    ✅ Fix: Luôn kiểm tra NULL trước khi dereference.

  • Dereference uninitialized pointer (Wild pointer)

    Pointer chưa khởi tạo chứa địa chỉ rác.

    int *p; // Chưa khởi tạo
    *p = 10; // ❌ Undefined behavior

    ✅ Fix: Khởi tạo pointer: int *p = NULL;

  • Dangling pointer (Use after free)

    Sử dụng pointer sau khi đã free bộ nhớ.

    int *p = malloc(sizeof(int));
    free(p);
    *p = 10; // ❌ Use after free

    ✅ Fix: Sau free, gán p = NULL;

  • Memory leak

    malloc mà không free, gây rò rỉ bộ nhớ.

    void func() {
      int *p = malloc(100);
      // Quên free(p);
    }

    ✅ Fix: Luôn free bộ nhớ khi không dùng.

  • Return address of local variable

    Trả về địa chỉ biến cục bộ — biến bị destroy khi hàm kết thúc.

    int* func() {
      int a = 5;
      return &a; // ❌ Dangling pointer
    }

    ✅ Fix: Dùng malloc hoặc truyền pointer vào hàm.

  • Pointer arithmetic sai kiểu

    Cộng pointer với số bytes thay vì số phần tử.

    int arr[10];
    int *p = arr;
    p = p + 4; // ✅ Tăng 4 phần tử (16 bytes)
    // p = (int*)((char*)p + 4); // ❌ Chỉ tăng 1 phần tử

    ✅ Fix: Hiểu rằng p+1 tăng sizeof(type) bytes.

  • Nhầm lẫn giữa * trong khai báo và dereference

    Nhầm * trong khai báo pointer với toán tử dereference.

    int *p, q; // ❌ Chỉ p là pointer, q là int
    // Đúng: int *p, *q; hoặc int *p; int *q;

    ✅ Fix: Khai báo riêng từng biến, hoặc nhớ * gắn với biến.

  • Quên & khi truyền vào hàm cần sửa biến

    Truyền value thay vì address khi muốn hàm sửa biến.

    void change(int *x) { *x = 10; }
    int a = 5;
    change(a); // ❌ Sai: truyền value
    change(&a); // ✅ Đúng: truyền address

    ✅ Fix: Nhớ dùng & khi gọi hàm nhận pointer.

  • Array-Pointer confusion

    Nhầm mảng với pointer — không thể gán mảng.

    int arr[10];
    int *p = arr; // ✅ OK
    arr = p; // ❌ Lỗi: arr là const pointer
    arr++; // ❌ Lỗi: không thể increment array

    ✅ Fix: Hiểu rằng tên mảng là const pointer.

  • Double free

    Free cùng một pointer hai lần.

    int *p = malloc(100);
    free(p);
    free(p); // ❌ Double free — crash

    ✅ Fix: Sau free, gán p = NULL. Free NULL là safe (no-op).

🛡️

Phòng ngừa lỗi:
1. Luôn khởi tạo pointer
2. Kiểm tra NULL trước khi dereference
3. Free bộ nhớ và gán NULL sau đó
4. Dùng tools như Valgrind để detect memory leaks
5. Compile với warnings: gcc -Wall -Wextra

🎯 Tổng kết

▸

Pointer là biến lưu địa chỉ của biến khác. Dùng & để lấy địa chỉ, * để dereference.

▸

C truyền tham trị — muốn hàm sửa biến ngoài, phải truyền địa chỉ bằng pointer.

▸

C++ có reference (int &x) — cú pháp gọn hơn pointer nhưng không có trong C.

▸

Array name là const pointer — không thể gán hay increment.

▸

Pointer arithmetic tự động nhân với sizeof kiểu dữ liệu.

▸

malloc/free dùng để cấp phát và giải phóng bộ nhớ động trên heap.

▸

Struct pointer dùng -> operator để truy cập fields.
