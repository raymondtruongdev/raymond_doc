C/C++ Pointer Masterclass

1. Giới thiệu về Con trỏ (Pointer)

Trong lập trình C/C++, Con trỏ (Pointer) là một trong những khái niệm mạnh mẽ nhất nhưng cũng dễ gây nhầm lẫn nhất. Hiểu về con trỏ chính là hiểu cách máy tính quản lý bộ nhớ.

"Con trỏ không phải là một giá trị thông thường, nó là một biến lưu trữ địa chỉ của một ô nhớ khác."

💡 Hình dung đơn giản:

Hãy tưởng tượng bộ nhớ là một dãy tủ có khóa. Biến int a là một ngăn tủ có nhãn "a" chứa số 5. Con trỏ int *p là một mảnh giấy ghi "số tủ: 0x1000" — nó không chứa số 5, mà chỉ ghi địa chỉ của ngăn tủ chứa số 5.

2. Biến và Bộ nhớ (Variable & Memory)

Mỗi khi bạn khai báo một biến (ví dụ: int a = 5;), máy tính sẽ dành riêng một khoảng không gian trong bộ nhớ (RAM) để lưu trữ giá trị đó. Mỗi khoảng không gian này có một "số nhà" duy nhất, gọi là địa chỉ (Address).

Stack Memory

Dùng để lưu trữ các biến cục bộ, tham số hàm. Tự động cấp phát và giải phóng khi hàm kết thúc.

Heap Memory

Dùng cho cấp phát động (malloc/new). Người lập trình phải tự quản lý (cấp phát và giải phóng).

Phân loại các vùng nhớ chính:

Vùng nhớ Đặc điểm Quản lý
Stack Biến cục bộ, tham số hàm. Kích thước nhỏ (~8MB). Tự động — cấp phát/giải phóng theo hàm.
Heap Dữ liệu cấp phát động. Kích thước lớn. Thủ công — dùng malloc() và free().
Data Segment Lưu biến global, biến static. Tự động — tồn tại suốt vòng đời chương trình.
Code Segment Chứa mã máy (instructions) của chương trình. Chỉ đọc, cố định.

3. Khái niệm cơ bản về Pointer

Để làm việc với con trỏ, bạn cần nắm vững hai toán tử quan trọng nhất:

&

Toán tử lấy địa chỉ (Address-of)

Trả về địa chỉ của biến.

*

Toán tử giải tham chiếu (Dereference)

Truy cập vào giá trị tại địa chỉ mà con trỏ đang trỏ tới.

Cách nhớ:
&a → "Địa chỉ của a" (address-of a)
*p → "Giá trị tại địa chỉ p" (value-at-address p)

Ví dụ minh họa:


#include 

int main() {
    int a = 5;
    int *p = &a; // p lưu địa chỉ của a

    printf("Gia tri cua a: %d\n", a);          // 5
    printf("Dia chi cua a (&a): %p\n", &a);    // Ví dụ: 0x7ffe...
    printf("Gia tri cua p: %p\n", p);          // Giống &a
    printf("Gia tri p tro toi (*p): %d\n", *p); // 5

    *p = 10; // Thay đổi giá trị tại địa chỉ p trỏ tới
    printf("Gia tri moi cua a: %d\n", a);      // 10

    return 0;
}

4. Cách khai báo Pointer

Trong C, có nhiều cách viết để khai báo một con trỏ, tất cả đều có ý nghĩa như nhau:

  • int* p; Style C++, nhấn mạnh kiểu dữ liệu là con trỏ int.
  • int *p; Style C truyền thống, nhấn mạnh p là một biến trỏ.
  • int * p; Khoảng trắng hai bên, ít dùng.

⚠️ CẢNH BÁO: Sự khác biệt quan trọng

Khi khai báo nhiều biến trên một dòng, hãy cẩn thận:


int* p1, p2; // SAI LẦM PHỔ BIẾN!
// p1 là con trỏ (int*), nhưng p2 chỉ là một số nguyên (int) thông thường.

int *p1, *p2; // ĐÚNG: Cả p1 và p2 đều là con trỏ.

5. Pass By Value vs Pass By Address

A. Pass By Value (Truyền tham trị)

Trong C, mặc định mọi tham số được truyền theo giá trị. Hàm nhận được một bản sao của biến gốc.

Tại sao lại ra 5?

Khi gọi change(a), chương trình thực hiện:

  1. Bước 1: Tạo bản sao x = a (x = 5).
  2. Bước 2: Gán x = 10 (chỉ sửa x, a không đổi).
  3. Bước 3: Hàm kết thúc, x bị hủy, a vẫn là 5.
Hai ô nhớ riêng biệt — a và x không liên quan
a = 5
0x1000
≠
x = 10
0x5000

#include 

void change(int x) {
    x = 10; // Chỉ thay đổi bản sao x
}

int main() {
    int a = 5;
    change(a);
    printf("%d\n", a); // Kết quả: 5 (a không đổi)
    return 0;
}

B. Pass By Address (Truyền tham địa chỉ)

Để thay đổi biến gốc, ta phải truyền địa chỉ của nó vào hàm thông qua con trỏ.


#include 

void change(int *x) {
    *x = 10; // Đi đến địa chỉ x trỏ tới và ghi 10 vào đó
}

int main() {
    int a = 5;
    change(&a); // Truyền địa chỉ của a
    printf("%d\n", a); // Kết quả: 10 (a đã thay đổi)
    return 0;
}

Tại sao dùng Pointer? Vì C luôn truyền bản sao. Chỉ khi truyền địa chỉ, hàm mới có thể truy cập trực tiếp vào ô nhớ gốc để thay đổi dữ liệu bên ngoài.

6. Tham chiếu trong C++ (C++ Reference)

C++ giới thiệu một khái niệm gọi là Reference (&). Nó giúp cú pháp gọn hơn so với Pointer trong C.


// C++ Reference
void change(int &x) {
    x = 10; // x là "bí danh" của a, sửa x là sửa a
}

int main() {
    int a = 5;
    change(a); // Không cần dùng dấu & khi gọi hàm
    // Kết quả: a = 10
}

C Pointer

  • - Cú pháp: `change(&a)`
  • - Bên trong: `*x = 10`
  • - Cần dùng toán tử `*` để truy cập

C++ Reference

  • - Cú pháp: `change(a)`
  • - Bên trong: `x = 10`
  • - Tự động như một "bí danh" (alias)

7. Các loại Pointer nguy hiểm

NULL Pointer

Con trỏ trỏ vào địa chỉ 0. Luôn luôn kiểm tra `if (p != NULL)` trước khi dùng để tránh crash chương trình.

int *p = NULL;

Wild Pointer (Con trỏ rác)

Con trỏ được khai báo nhưng chưa được khởi tạo giá trị. Nó trỏ vào một địa chỉ ngẫu nhiên trong bộ nhớ.

int *p; // ❌ Cực kỳ nguy hiểm

Dangling Pointer (Con trỏ lơ lửng)

Con trỏ trỏ tới một vùng nhớ đã bị giải phóng (ví dụ sau khi gọi `free()`).

free(p); // p trở thành dangling pointer nếu không gán NULL

NULL PointerGán NULL có chủ đíchCrash (Segfault) nếu dereference
Wild PointerChưa khởi tạoUndefined behavior, ghi đè dữ liệu rác
Dangling PointerBộ nhớ đã free/hết scopeUse-after-free, lỗi logic khó tìm

8. Mảng và Phép toán con trỏ

Trong C, tên mảng thực chất là địa chỉ của phần tử đầu tiên.


int arr[3] = {10, 20, 30};
int *p = arr; // p trỏ tới arr[0]

printf("%d\n", *p);       // 10
printf("%d\n", *(p + 1)); // 20 (Pointer Arithmetic)
printf("%d\n", p[2]);     // 30 (Cách viết mảng)

Lưu ý: Phép toán trên con trỏ tự động nhân với kích thước kiểu dữ liệu.

0x1008

...

9. Quản lý bộ nhớ động (malloc/free)

Khi không biết trước cần bao nhiêu bộ nhớ, ta dùng Heap.


#include 

int main() {
    // Cấp phát cho 5 số nguyên
    int *arr = (int*)malloc(5 * sizeof(int));

    if (arr == NULL) return 1; // Kiểm tra lỗi cấp phát

    for(int i=0; i<5; i++) arr[i] = i * 10;

    free(arr); // QUAN TRỌNG: Phải giải phóng để tránh Memory Leak
    return 0;
}

Memory Leak là gì? Nếu bạn malloc() mà quên free(), bộ nhớ không được trả lại cho hệ thống. Dùng công cụ Valgrind để kiểm tra rò rỉ: valgrind ./program

Best Practices:

  • Luôn kiểm tra NULL sau khi malloc.
  • Luôn free() bộ nhớ để tránh Memory Leak.
  • Gán pointer bằng NULL ngay sau khi giải phóng.

10. Struct Pointer — Con trỏ đến cấu trúc

Dùng pointer với struct giúp tránh copy toàn bộ dữ liệu, tiết kiệm bộ nhớ khi truyền vào hàm.


typedef struct {
    char name[50];
    int age;
} Student;

void update(Student *s) {
    s->age = 21; // Dùng toán tử -> để truy cập field
}

int main() {
    Student sv = {"Nam", 20};
    update(&sv);
    return 0;
}

Toán tử s->age là cách viết tắt của (*s).age. Dùng pointer với struct giúp tránh copy toàn bộ struct khi truyền vào hàm, giúp chương trình chạy nhanh hơn.

11. Const Pointer — Con trỏ hằng

Kết hợp const giúp bảo vệ dữ liệu khỏi việc bị thay đổi vô ý. Đọc từ phải sang trái để hiểu ý nghĩa:

Quy tắc: Đọc từ phải sang trái. const áp dụng cho phần tử đứng ngay bên trái nó.

Khai báoÝ nghĩaKhả năng
const int *p
int const *p		 "p là pointer đến int const" ❌ Không sửa được giá trị
int * const p Pointer hằng đến int ❌ Không đổi được địa chỉ
const int * const p Cả hai đều hằng ❌ Không sửa được gì 

int a = 10, b = 20;
const int *p1 = &a; 
// p1 = &b; (OK)
// *p1 = 15; (LỖI)

int * const p2 = &a;
// *p2 = 15; (OK)
// p2 = &b; (LỖI)

10. 10 lỗi Pointer thường gặp

1. Dereference NULL pointer

Truy cập giá trị qua pointer NULL gây crash chương trình ngay lập tức.

int *p = NULL;
printf("%d", *p); // ❌ SEGMENTATION FAULT
✅ Fix: Luôn if (p != NULL) trước khi dùng.
2. Wild Pointer (Chưa khởi tạo)

Con trỏ chứa địa chỉ rác ngẫu nhiên.

int *p; // Chưa khởi tạo
*p = 10; // ❌ Ghi vào địa chỉ ngẫu nhiên
✅ Fix: Gán NULL ngay khi khai báo.
3. Dangling Pointer (Dùng sau khi free)

Vùng nhớ đã bị thu hồi nhưng con trỏ vẫn trỏ tới.

free(p);
*p = 5; // ❌ Lỗi Use-after-free
✅ Fix: Gán p = NULL ngay sau khi free().
4. Memory Leak

Mất dấu địa chỉ vùng nhớ heap mà chưa giải phóng.

void f() { int *p = malloc(100); } // ❌ p mất khi hàm kết thúc, memory leak!
✅ Fix: Luôn free(p) trước khi gán địa chỉ mới cho p.
5. Trả về địa chỉ biến cục bộ

Biến cục bộ bị hủy khi hàm kết thúc, địa chỉ trở nên vô nghĩa.

int* get() { int a = 5; return &a; } // ❌ a nằm trên stack, bị xóa sau khi return
✅ Fix: Dùng malloc để cấp phát trên heap hoặc dùng tham số truyền vào.
6. Double Free

Giải phóng một ô nhớ hai lần gây hỏng bộ quản lý bộ nhớ.

free(p); free(p); // ❌ Lỗi crash
✅ Fix: Gán NULL sau free. free(NULL) là an toàn.
7. Pointer Arithmetic sai kiểu

Cộng pointer với số byte thay vì số phần tử.

✅ Fix: Hiểu rằng p + 1 tăng sizeof(type) bytes.
8. Quên dấu & khi truyền hàm
void change(int *x); int a=5; change(a); // ❌ Sai kiểu
✅ Fix: change(&a);
9. Nhầm lẫn tên mảng và Pointer
int arr[10]; arr++; // ❌ Lỗi: mảng là hằng số địa chỉ
✅ Fix: Dùng một biến pointer phụ int *p = arr; p++;
10. Dereference void* mà không ép kiểu
void *p = &a; *p = 10; // ❌ Lỗi: trình biên dịch không biết p trỏ tới gì
✅ Fix: *(int*)p = 10;

🛡️ 5 Chiến lược phòng ngừa:

  • 1. Khởi tạo: Luôn gán NULL cho pointer mới khai báo.
  • 2. Kiểm tra: Luôn check != NULL trước khi dùng toán tử *.
  • 3. Dọn dẹp: free() xong là phải gán NULL ngay.
  • 4. Công cụ: Dùng Valgrind hoặc Sanitizers để bắt lỗi bộ nhớ.
  • 5. Cẩn trọng: Hạn chế dùng Raw Pointer, ưu tiên Reference trong C++.

🎯 Tổng kết kiến thức

• Bản chất: Con trỏ là biến lưu địa chỉ.

• Toán tử: & (lấy địa chỉ), * (truy cập giá trị).

• Truyền hàm: C truyền tham trị, muốn sửa biến gốc phải dùng pointer.

• C++ Reference: Bí danh của biến, cú pháp sạch hơn pointer.

• Mảng: Tên mảng là một con trỏ hằng (không đổi địa chỉ được).

• Heap: Bộ nhớ động cần malloc() và free() thủ công.

• Struct: Dùng toán tử -> để truy cập nhanh qua pointer.

• Const: Dùng bảo vệ dữ liệu (pointer to const vs const pointer).
