C Pointer Master Guide

Tài liệu đầy đủ dành cho người mới học C, Embedded, RTOS và Firmware.

1. Variable và Memory

Mỗi biến chiếm một vùng nhớ trong RAM.

int a = 5;
Address 0x1000
+-----+
| 5 | ← a
+-----+

a là giá trị. &a là địa chỉ.

2. Pointer là gì?

Pointer là biến dùng để lưu địa chỉ bộ nhớ.

int a = 5;
int *p = &a;
p -----> a -----> 5

3. Cách khai báo Pointer

int *p;
int* p;
int * p;

Ba cách trên hoàn toàn giống nhau.

int* p1, p2;
p1 là pointer nhưng p2 chỉ là int. 
int *p1, *p2;

Cả hai đều là pointer.

4. Dấu *

Ý nghĩa 1: Khai báo Pointer

int *p;

Ý nghĩa 2: Dereference

printf("%d", *p);

Ý nghĩa 3: Phép nhân

int x = 3 * 4;

5. Dấu &

int a = 5;

printf("%p", &a);

&a trả về địa chỉ của biến a.

6. Pass By Value

void change(int x)
{
    x = 10;
}

x chỉ là bản sao.

7. Pass By Address

void change(int *x)
{
    *x = 10;
}
change(&a);

Hàm có thể sửa trực tiếp biến gốc.

8. C++ Reference

void change(int &x)
{
    x = 10;
}

Reference không tồn tại trong C.

9. NULL Pointer

int *p = NULL;

Pointer chưa trỏ tới vùng nhớ hợp lệ nào.

10. Wild Pointer

int *p;

*p = 10;

Undefined Behavior.

11. Dangling Pointer

free(p);

Sau free, pointer vẫn còn địa chỉ cũ.

free(p);
p = NULL;

12. Array và Pointer

int arr[3] = {1,2,3};
arr == &arr[0]
*arr       // 1
*(arr+1)   // 2
*(arr+2)   // 3

13. Pointer Arithmetic

int arr[3];

int *p = arr;

p++;

Nếu sizeof(int)=4 thì pointer tăng thêm 4 byte.

14. malloc và free

int *p = malloc(sizeof(int));

*p = 123;

free(p);
p = NULL;
STACK HEAP p -------> +-----+ |123 | +-----+

15. Struct Pointer

typedef struct
{
    int age;
} Person;

Person p;

Person *ptr = &p;

ptr->age = 20;

16. Const Pointer

const int *p;

Đổi địa chỉ được, không đổi dữ liệu.

int *const p;

Đổi dữ liệu được, không đổi địa chỉ.
