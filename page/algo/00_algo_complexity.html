Detailed Guide to 11 Complexity Patterns

Hướng dẫn chi tiết về 11 Mẫu Độ Phức Tạp thuật toán

Tổng quan: Cách tính độ phức tạp

Độ phức tạp thuật toán là một khái niệm quan trọng trong khoa học máy tính, giúp chúng ta đánh giá hiệu suất của các thuật toán dựa trên số lượng phép tính hoặc bộ nhớ cần thiết khi kích thước đầu vào tăng lên.

Độ phức tạp thuật toán (Big O notation) dùng để đo lường mức độ tăng trưởng thời gian hoặc không gian khi đầu vào \(n\) tiến tới vô hạn. Các quy tắc tính toán bao gồm:

  • Quy tắc bỏ hằng số: \(O(2n) = O(n)\), \(O(n + 100) = O(n)\).
  • Quy tắc cộng (tuần tự): Nếu hai vòng lặp nối tiếp, ta lấy tổng: \(O(n) + O(n) = O(n)\).
  • Quy tắc nhân (lồng nhau): Nếu vòng lặp lồng nhau, ta nhân: \(O(n) \times O(n) = O(n^2)\).
  • Quy tắc bỏ số hạng thấp: Trong tổng, chỉ giữ lại hạng tử có tốc độ tăng nhanh nhất: \(O(n^2 + n) = O(n^2)\).


1. O(n) - Vòng lặp đơn

Số phép tính tỉ lệ thuận với số phần tử.

for (int i = 0; i < n; i++) { 
    // Các lệnh bên trong tốn O(1)
}

2. O(n²) - Vòng lặp lồng

Với mỗi i, j chạy n lần: \(n \times n = n^2\).

for (int i = 0; i < n; i++)
    for (int j = 0; j < n; j++) { }

3. O(n²) - Tam giác

Số phép tính: \(\sum_{i=1}^{n} i = \frac{n(n+1)}{2} \approx \frac{1}{2}n^2 \to O(n^2)\).

for (int i = 0; i < n; i++)
    for (int j = 0; j < i; j++) { }

4 & 5. O(log n) - Tăng trưởng Logarit

Biến i thay đổi theo cấp số nhân: \(i = 2^k \implies k = \log_2 n\).

for (int i = 1; i < n; i *= 2) { } // i: 1, 2, 4, 8...

6. O(n) - Tỉ lệ hằng số

Thực hiện \(n/2\) bước. Trong Big O, bỏ qua hằng số: \(O(n/2) = O(n)\).

for (int i = 0; i < n / 2; i++) { }

7. O(n) - Vòng lặp nối tiếp

Tổng số bước là \(n + n = 2n\). Bỏ qua hằng số: \(O(n)\).

for (int i = 0; i < n; i++) { }
for (int i = 0; i < n; i++) { }

8. O(log n) - While chia đôi

Giá trị n giảm một nửa mỗi vòng. Số vòng lặp là \(\log_2 n\).

while (n > 0) { n /= 2; }

9. O(n) - Đệ quy tuyến tính

Phương trình đệ quy: \(T(n) = T(n-1) + C \to O(n)\).

10. O(n log n) - Chia để trị

Áp dụng Master Theorem cho bài toán: \(T(n) = 2T(n/2) + n\).

11. O(φⁿ) - Tỉ lệ vàng

Đệ quy Fibonacci không khử đệ quy tốn \(O(1.618^n)\).

int f(int n) { 
    if (n <= 1) return n;
    return f(n - 1) + f(n - 2); 
}
